## Role

Person responsible for tracking personal or assigned work across a changing set of priorities.

## Desired Outcomes

- Capture work before it is forgotten.
- Quickly understand unfinished and completed work.
- Update task state as work progresses.
- Return later without recreating task context.

## Triggers and Behaviors

- Creates a task when a new obligation or follow-up is identified.
- Reviews tasks when planning work or deciding what to do next.
- Updates or completes a task after work changes.
- Abandons a tool when tasks are difficult to find or changes are uncertain.

## Constraints

- Has limited time to record work.
- May work across personal and shared contexts.
- Needs confidence that protected work is not visible to the wrong person.

## Pain Points

- Work is scattered across notes, messages, and spreadsheets.
- Ownership and current state are easy to lose.
- Repeated authentication or unclear failures interrupt work.

## Success Criteria

- Can record and later find a task without external notes.
- Can identify current task state and ownership.
- Can complete normal task actions without support intervention.
